# 本地账户与研究输出

paper 账户及研究输出统一使用 Parquet；图表和 HTML 是展示产物。
每个账户用 CURRENT 指向最新完整快照，历史快照保留用于核对。
M2 研究采用不可覆盖的独立目录：登记、完整数据证据、候选选择、比较、
逐日账本和归因均为 Parquet，另含源码/依赖版本和全量哈希。研究目录不使用 CURRENT。
运行 `invest verify-study --study <目录>` 可用同版引擎逐表重算。
新研究使用绑定引擎的 v2 登记；旧 v1 归档仍保留，可用 `--hashes-only` 检查完整性。
不要向旧登记补写指纹或改写其时间；源码变更后新建登记，已观察的区间只作为历史复核。
本目录除说明外默认忽略。不要手工修改账户快照来改变交易记录或恢复停用账户。
