# 本地账户与研究输出

paper 账户及研究输出统一使用 Parquet；图表和 HTML 是展示产物。
M1 账户用 CURRENT 指向最新完整快照，历史快照保留用于核对。
M2 研究采用不可覆盖的独立目录：登记、完整数据证据、候选选择、比较、
逐日账本和归因均为 Parquet，另含源码/依赖版本和全量哈希。研究目录不使用 CURRENT。
运行 `invest verify-study --study <目录>` 可用同版引擎逐表重算。
新研究使用绑定引擎的 v3 登记，并可冻结 `known_history` 声明；v2 仍可读取。
旧 v1 归档仍保留，可用 `--hashes-only` 检查完整性。
不要向旧登记补写指纹或改写其时间；源码变更后新建登记，已观察的区间只作为历史复核。
本目录除说明外默认忽略。不要手工修改账户快照来改变交易记录或恢复停用账户。
M3 使用 `journal/<连续序号>/`，目录发布即提交，不使用 CURRENT。
`forward-verify` 重放事件、风险状态并独立对账；`forward-backup` / `forward-restore`
保持同一账户 ID 与资本，恢复后暂停。合成故障演练与真实现金观察分别保存，不混作策略证据。
