# 本地 Paper 账户 MVP

目标是验证“行情 → 信号 → 成交 → 账户 → 风险 → 报告”的完整流程。
首版不连接任何券商，也不调度真实资金。账户初始资金默认 5,000 美元。

## 信号与成交

收盘价高于包含当日在内的 N 日简单均线且空仓时，按目标仓位和已知收盘价计算整股订单；
最早下一条日线开盘执行。开盘跳空导致买不起时，仅按当时现金和仓位预算缩减数量。
持仓时收盘价不高于均线则退出。最后一日生成的订单保留，不在回测终点强行成交。
无成交量时延迟待成交订单，原决定保留；风险停用可以取消买单或替换为退出订单。

每笔成交扣固定费用。买入成交价上浮、卖出下浮指定基点；所有交易决策日期和成交日期
分开记录。股数预算在前一收盘产生，不能因已知第二天上涨而扩大订单。
不模拟盘口、容量约束、盘中止损触达或真实部分成交；日成交量只用于零成交过滤。

日终净值 = 现金 + 持仓数量 × 原始收盘价 + 尚未支付的分红应收款。
所有费用计入净值，期末浮动盈亏不能被遗漏。基准从相同预热期结束后的下一交易日
开盘开始买入，采用相同仓位预算和成本，此后持续持有，不采用策略风控退出。

## 研究默认值

| 项目 | 默认值 | 性质 |
| --- | --- | --- |
| 初始资金 | 5,000 美元 | 项目起点 |
| 均线窗口 | 20 日；演示配置 5 日 | 待验证的研究参数 |
| 单标的资金分配 | 80% | 待验证的研究参数，仅开仓时约束 |
| 每单费用 | 1 美元 | 模拟假设，不代表嘉信或 Alpaca 费率 |
| 单向滑点 | 5 基点 | 模拟假设 |
| 单仓止损 | 成本回撤 8% | 待验证的研究参数 |
| 单仓利润回撤 | 持有期价格高点回撤 12% | 待验证的研究参数 |
| 账户利润回撤 | 账户日终净值高点回撤 15% | 待验证的研究参数 |
| 本金警戒 | 低于初始本金的 80% | 交接中记录的硬边界 |
| 项目终止 | 不高于初始本金的 50% | 交接中记录的硬边界 |

单仓成本包含买入费用。单仓利润保护基于原始价格峰值，账户保护基于含现金分红的
完整净值；分红除息可能影响价格止损，需要在真实数据研究阶段单独评价。

## 风险状态

- `active`：允许按策略开仓或退出。
- `warning`：低于本金警戒线后停止新开仓、安排下一可成交开盘退出，等待人工复核。
- `halted`：账户高点回撤触发停用，同样安排退出。
- `terminated`：达到本金终止线，取消开仓并安排清仓。

终止状态优先级最高，其次是账户回撤停用。即使已经停用，跌破本金警戒线也会单独
记录事件。所有非 active 状态均保留，不会因盈利反弹、账户清空或程序重启自动恢复。
首版没有“恢复交易”按钮，需要明确复核后另建账户；不得通过重启绕过风险状态。

规则均按日终观测、后续开盘执行。跳空、缺失行情或无成交量可能造成更大损失；
2,500 美元是触发边界，不是保本成交价。单仓退出后允许后续新信号重新开仓；
账户级停用则保持。警戒后的动作及上述研究参数是当前实现选择，不等于用户已经批准实盘。

## 重启与一致性

每次从累计原始数据重放相同会计引擎，随后生成完整的不可变快照。相同输入不新增快照；
追加数据的结果必须与一次性完整重放一致。源码校验值、配置、输入文件校验值和版本
记录在 Parquet 中。文件锁阻止并发更新，所有文件和图表成功写出后才原子切换 CURRENT。
更新失败时旧快照仍是当前状态；这不替代磁盘备份或断电耐久性保障。

当前只支持单账户单标的。多标的资金竞争、真实市场数据接入、交易日历完整性、
实时调度和券商订单适配将在后续阶段加入。人工样例只证明软件可运行，不能证明收益。

## Alpaca 的使用时机

先通过真实历史数据检验模型，并用本地账户逐日追加行情观察信号与风险行为。
当需要测试外部订单生命周期、网络断连重试、撤单和成交核对时，再接 Alpaca paper。
届时保留本地账本作为核对基准。Alpaca 的成交模拟及权限也不能代替嘉信账户验证。
当前不需要 API 凭据。
