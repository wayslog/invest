# T09：IBKR 唯一可信来源的接入核查

初次核查日期：2026-10-20；当前来源决策更新于 2026-10-22（北京时间）。
**IBKR 是行情、账户、委托、成交与费用的唯一可信外部来源。**
已完成公开资料、SDK 离线检查及 2026-10-23 的 VPS Paper API 会话验证；
尚未取得完整账户快照、行情权限或订单联调回执。
“选定来源”与“已取得账户和数据回执”分别记录，完整政策见 [数据来源决策](../data-sources.md)。

## 已知事实与缺口

| 项目 | 已有事实 | 接入时需确认 |
| --- | --- | --- |
| IBKR 账户 | 用户确认已入金；VPS API 会话返回一个 Paper 账户 | 账户分类、币种、余额、持仓及交易权限 |
| 连接方式 | VPS 本地 `127.0.0.1:4002` 已通过 SDK 会话检查，协商协议版本 178 | Gateway 应用版本、常驻运行及定期重新认证 |
| Python SDK | `ib_async 2.1.0` 已在独立 Python 3.12 环境通过安装、导入和未发送订单对象检查 | 与实际网关的版本兼容性、请求完成及断线恢复；当前 M3 依赖锁仍未变更 |
| 行情 | 官方支持历史日线/分钟线及实时、冻结、延迟报价 | SPY/XLF 的实际订阅、数据类型、历史覆盖、时间与成交量单位 |
| 价格及企业行动 | IBKR 的历史 TRADES 已调整拆股，ADJUSTED_LAST 还调整分红 | 与现有原始价格账目的规范化方式，以及必要事件日期和金额的实际可得性 |
| 订阅成本 | 非专业用户 Network B 公开价为 1.50 美元/月；全免费不是选型前提 | 本账户实际套餐、分类、账单和 Paper 共享；当前没有已购订阅证明 |
| 订单与成交 | API 提供下单、撤单、状态及成交回报，Paper 为模拟撮合 | 委托标识关联、拒单/部分成交/撤单、超时查询、重连核对及费用迟到 |
| 账户流水和报表 | IBKR API、券商报表和 Flex 是目标账务来源 | 本账户可用范围、历史区间、费用和分红/拆股字段；尚无实际回执 |

SDK 的方法存在、公开资料可访问以及 Paper UI 登录，都不替代实际数据和权限回执。
IBKR 未提供的必要字段记录缺口；不把 Alpaca、发行方或本地推测静默填成 IBKR 数据。

## 实施顺序

1. T11 先连接已登录的 IB Gateway/TWS **Paper Trading** 会话，开启网关 Read-Only API，
   读取账户、现金、持仓、已有订单及成交，核查 SPY/XLF 合约。
2. 只读试取历史、实时和延迟行情，保存原始 Parquet/Zstandard、实际行情类型及数据时间，
   对照价格调整、常规时段、单位和事件字段，形成 IBKR 规范化与数据验收记录。
3. T12 并行实现订单状态机、客户订单关联、重试幂等、超时查询及重连对账，先离线验证，
   再开展 Paper 委托、撤单、部分成交及费用核对。订单记录以 IBKR 确认为依据。
4. 明确券商账户与项目 5,000 美元资金账本的映射；Paper 初始余额不能自动替换已有本金、
   高点或风险状态。切换数据和引擎保留原账户、旧日志及原观察窗口。

本地离线实现可与 M3 运维观察并行，不必等待 60 日窗口结束。
当前 `0.6.1` 的线上 M3 仍是旧 Alpaca 采集链路；文档更新没有切换生产服务。
旧观察仅记录原来源下的运行证据，不能写成 IBKR 已接入或已完成真实订单验收。
