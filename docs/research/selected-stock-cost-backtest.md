# 选中股票的含成本趋势研究

本流程把已选中的少量股票放进独立、共同现金的模拟组合，输出历史含成本回测与当前空仓的条件动作。它检验预先固定的交易假设；不会把关注列表转换成合格因子池，也不改变 `mine`、`backtest`、`decide` 的正式准入。

它只验证固定候选池中的交易规则，未验证每周重建 SPY/QQQ 成员、重新选股和引入池外股票。
完整选股系统按[周度动态回测规范](weekly-dynamic-backtest.md)实现与验收；原研究结果和状态保留。

## 输入和冻结

- 发行方、交易所与 Alpaca 原始证据先冻结，再导入原价 USD Parquet 快照及含公司行动的成交输入。来源保持 `alpaca`、范围保持 `exploratory`。
- 股票与 SPY 使用相同交易日历，首笔成交前至少 253 个完整会话。当前原价规则要求整个指标和回测区间没有拆股。
- 先记录 `rule-design.toml` 的原始字节、SHA256、登记时刻和试验数到 `rule-registration.parquet`，再计算收益。修改设计必须作为新试验保留。
- 此次 VLO、FTNT、ILMN 的共同数据区间从 2024-07-01 开始，避开 ILMN/GRAIL 分拆；首个决策日为 2025-07-03，回测成交从 2025-07-07 至 2026-10-23。原始分拆事件仍在采集证据中。
- 三只股票是用截至 2026-10-23 的历史筛出的。因此这次为 `known_history_post_selection`，不是独立样本外验证，也不是历史 518 股漏斗的收益。

发行方现金分红核对支持本次有限区间。VLO 官网显示除息日与 Alpaca 相差一个交易日；保留原值，只有满足提前宣告、普通现金、低于股价 25%、记录日为交易日等条件，才按照冻结的 NYSE T+1 规则核对实际除息日。金额和支付日必须同时一致。FTNT、ILMN 的无现金分红核对要求当前政策、历史年报和 Alpaca 事件相互一致。详见[公司行动证据](../access/selected-stock-actions-20261026.md)。

## 这次固定的交易规则

1. 每日收盘计算 Qlib 指标：价格高于 200 日均线；126 会话收益为正且高于 SPY；252 会话剔除最近 21 会话的收益高于 SPY；价格至少 10 USD；20 会话平均成交金额至少 2,000 万 USD；63 会话年化波动不超过 60%；253 会话最大回撤不超过 30%。所有条件同时满足才有入场资格。
2. 共用 5,000 USD、空仓、整股、不融资。每 5 个交易会话重新分配，单股目标上限为净值的 25%，总目标上限 75%；不足整股部分保留现金。5 会话周期不等同固定周一。
3. 收盘决定，下一交易会话开盘模拟成交；每笔买入或卖出佣金 1 USD，买入加、卖出减 5 bps 滑点。开盘跳价时按预算缩量，不透支现金。另跑佣金 2 USD、滑点 10 bps 压力情景。费用是研究假设，不是券商实际报价；结果为税前。
4. 以含买入佣金的平均成本设置 8% 固定止损、20% 止盈；以已知收盘经济价格高点设置 12% 跟踪止损。分红权益调整风险价格，现金在支付日入账。开盘跳空按开盘加减滑点；同一日线同时触及止损和止盈时先算止损。止损不能保证最大亏损为 8%。
5. 最多持有 60 会话；每日收盘不再符合入场条件则发出下一会话离场动作，无须等待再平衡。退出后冷却 5 个完整会话；账户从峰值回撤达到 15% 时清仓并停止新买入，不自动重置资金或风险状态。
6. 卖出资金按下一会话可用，成交量不超过上一会话成交量的 1%。以上成交模型是日线近似，无法还原真实盘口路径。

## 运行和产物

输入配置只连接冻结设计和数据路径：

```toml
design = "rule-design.toml"
snapshot = "imported/snapshot"
benchmark_snapshot = "benchmark-snapshot"

[execution]
VLO = "imported/execution/VLO.parquet"
FTNT = "imported/execution/FTNT.parquet"
ILMN = "imported/execution/ILMN.parquet"

[benchmark_execution]
SPY = "benchmark-execution/SPY.parquet"
```

```sh
uv run --locked --group research invest trend-backtest --config <inputs.toml> --output <new-study>
uv run --locked --group research invest verify-trend-backtest --study <new-study>
```

输出包括五个情景：趋势策略、同风险等权参考、现金、双倍成本、SPY 参考。SPY 使用整股和相同成本，关闭个股退出，保留引擎账户保护；必须检查其成交和风险事件后再描述是否全程持有。

`metrics.parquet`、`costs.parquet`、逐笔成交、净值、现金分红、完整交易周期和独立账务核对均为正式 Parquet。胜负按空仓到再次空仓的完整周期净损益评定，含费用和分红；未平仓损益计入净值但不计胜率。`current_context.parquet`、`current_actions.parquet` 始终用独立 5,000 USD 空仓上下文，与回测末期账户分开。参考止损止盈须按实际开盘成交成本重算。

每次运行使用新目录，复制输入、来源证据、设计、引擎和依赖版本并封存清单；失败结果也保留。重放核对全部结果表和来源元数据。引擎变化后，使用产物内冻结的 `engine` 与对应依赖重放。历史账户、注册、研究和样本外状态不修改；所有动作均为研究模拟，不提交券商订单。
