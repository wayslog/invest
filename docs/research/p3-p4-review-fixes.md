日期：2026-10-24。基线：`e22581e`。状态：已通过本地离线验收。

本次只修复统一决策、研究冻结与独立审计的六项问题。历史账户、研究及其原冻结源码保持不变，
没有部署、迁移、账户重置或券商订单操作。

## 行为修正

| 问题 | 修复后的规则 |
| --- | --- |
| 成交关联到其他证券的订单仍通过审计 | 除订单 ID、方向、数量和时序外，独立审计还检查证券身份；交换同价同量成交的订单 ID 会失败 |
| 复制后的挖掘来源与登记不一致仍完成或通过重放 | 从已核验的同一批字节读取因子池、登记、完成记录和配置；冻结后重新核对，读取策略和重放时再次校验来源链 |
| 未准入报价影响其他持仓的减仓 | 持仓估值不全时不计算组合 NAV，不做排名调仓或敞口减仓；保留可靠报价支持的独立退出，保留原净值高点与风险状态 |
| 条件失效的待买单没有取消需求 | 待买单复用报价、股票池、有效信号、冷却、账户风险和操作状态准入；不合格时输出取消需求，实际确认前继续占用资金和敞口 |
| 风险条件改变后动作 ID 不变 | 对完整保存动作的规范化语义生成身份，包含取消需求、退出原因和有效期；Decimal 往返不改变身份 |
| 晚到高点导致独立审计误拒绝保护性成交 | 审计接收同一行情时点输入，独立重建准入后的高点；缺失记录不等于允许探索的未知时间 |

金额继续使用美元 Decimal，股数为整股，日期使用 XNYS 会话。
缺价时动作的 `reference_price` 为空；组合净值未知时 `target_weight` 为空。
有可靠报价支持的止损、止盈、股票池退出和原风险锁继续有效。
这里只生成取消建议，不表示订单已取消；待买单自身报价不可用时，按其原参考价保留预算。

回测登记新增 `mining_manifest_sha256`，绑定最初验证的挖掘清单。
只复制重放所需的来源文件，原完整清单和原始研究仍保留。
即使外层研究清单自洽，也必须核对内部挖掘文件、注册身份、配置和因子池之间的关系。
复制期间发生替换会保存失败记录，不生成正式动作。

这些变化属于金融行为修正；已有研究继续使用各自冻结源码重放，不能用新源码覆盖旧结果。
`actions.v2` 保持原有可空字段模式；新动作 ID 不追改历史 ID。
