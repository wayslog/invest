# QQQ 超额收益归因与下一轮改进

本轮只诊断既有固定 513 股票研究，不修改正式选股配置、交易规则或任何历史账户。
QQQ 含成本买入持有仍是主基准。当前名单回看历史有幸存者偏差；已经查看的历史不能重新标为未触碰样本外。

## 已完成的诊断

- 使用 `return_attribution.portfolio_attribution`，逐日将净超额收益拆为仓位配置、期初持仓选股、实际交易时点及成本四项。仓位配置包含何时持有现金的影响，不能用平均仓位乘区间涨幅替代。
- 按实际拆股调整期初股数，分红在除息日计入应收；佣金与滑点来自实际成交。使用对称复利连接，使四项精确加总到两账户区间收益之差。交易项保留盘中进出与再配置影响，不称为纯选股能力。
- 原账户的逐股 Decimal 损益独立核对期末净值；归因用浮点分析表，不能据此重建、覆盖财务账本。
- 在前轮已查看的「仅进出场」方案上预先登记 18 条控制路径：退出规则三组完整组合，以及单项止损、技术退出、冷却、仓位、削仓和零成本控制。继续使用同一时序、交收、公司行动及连续账户审计。
- 对冻结的周度评分计算下一会话开盘至第 5、20、60 会话收盘的含息收益标签，分红不再投资。缺失行情、未支持公司行动及右端不足期数单独列出，不填零。标签仅用于事后评价。
- 评分 IC 在相应可评分截面上计算；多周标签存在重叠，采用说明了滞后阶数的 HAC 标准误。分季度、分项及多重尝试均保留，不能把显著性读作未来收益保证。

正式结果与原始路径存放在忽略的 `reports/qqq-attribution-20261026-v1/`，均为 Parquet/Zstandard；HTML 和图表只展示这些表。

## 诊断结论

1. 主动策略的主要约束是候选稀疏、低股票仓位及空仓时机。提高总仓位配置本身无法解决单股上限和缺少候选的问题。
2. 评分存在一定历史排序信息，但风险低就加分的收益假设与本段历史不吻合；绝对分数门槛、风险硬筛及仓位上限叠加，使信息未转化为充分投资。
3. 固定止盈、硬止损和日常削仓对本段收益有实质影响，且规则之间有交互。取消全部退出、取消冷却或取消单股约束均不是普遍改进。
4. 交易成本并非主要差距来源。零成本重新运行也未达到 QQQ；成本改变整股预算、保护价和后续路径，不能把重跑差异等同于原账本直接费用。
5. 首期名单满仓长期持有的失败属于该篮子的选股结果，不能归咎于现金。实际持有过的股票有正贡献，也不能证明首期固定名单能长期胜出。

## 按优先级推进

### 1. 将闲置资金规则纳入策略

预登记一个 QQQ 承接剩余预算的版本：个股仍受既有单股和总预算约束，剩余可投资预算配置 QQQ。没有合格个股时，可回到 QQQ；账户停仓状态仍须服从原风控，不能借此重置。保留必要交收及费用准备金，不使用融资。

QQQ 补仓和赎回必须经过同一个 Decimal 账户、真实可用现金、下一会话成交和成本计算；不能把原股票收益简单叠加 QQQ 收益。输出同时展示个股、QQQ 和现金三部分。

### 2. 让评分负责排序，风险负责仓位

先保留既有动量、趋势和流动性来源。对低波动、低回撤从「收益加分」移到「风险预算」的改法做单独对照；不一次加入大量新因子。预登记相对排名选取 3–5 个研究候选的方案，并与原 70 分硬门槛比较。候选不足时由 QQQ 补足预算，不强迫买入不合格个股。

收益标签和验收改为相对 QQQ 的含成本增量。把 SPY 改写成 QQQ 不会自动产生更好的截面排名：对所有股票减去同一个基准收益，排序不会变；真正需要检验的是准入门槛与未来超额收益的关系。

### 3. 简化退出与重配，保留风险约束

优先测试取消固定 20% 止盈；硬止损改为依据波动确定距离、按固定亏损预算反推股数的独立候选版本。保留技术失效退出、冷却和账户风控，持有期限制另做对照。任何无止损历史赢家都只作为诊断，不直接晋升策略。

每周继续计算漏斗；不用每周强制卖出落选股票或把小幅上涨的仓位削回目标。研究独立退出及容忍带重配，并单独核算交易次数、成本和风险变化。低回撤不是跑赢 QQQ 的替代验收标准。

### 4. 冻结少量组合后做新的验证

先分别检验现金承接、排序/风险分离、退出和重配改动，再组合通过的改动；记录每个尝试。历史分段、退出后继续上涨标签和本轮最优组合都是已知历史诊断，不是新样本外证据。

下一轮需要覆盖不同市场状态的未用于调参区间，或冻结参数后开始前向模拟。以同资金、同成本 QQQ 的净超额收益为主指标，同时报告回撤、资金利用率、成本压力和逐股集中度。不得修改旧研究身份、冻结输入和结果来制造胜率。

方法参考：[CFA Institute：Portfolio Performance Evaluation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/portfolio-performance-evaluation)。本项目的四项恒等归因是明确说明口径的实现，并非行业中立回归或标准多行业 Brinson 分类。
