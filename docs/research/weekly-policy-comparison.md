# 周度动态选股的两种落选策略比较

2026-10-26 用户明确要求用回测比较两种行为：按评分选择更好的股票而退出，或继续持有直到触发原退出条件。本文件记录待执行的对照实验；未产生收益结果，不能据此宣布任一版本更好。

用户随后明确只使用免费数据源。目标区间和每周历史 ETF 持仓口径保持原样；不会为绕开缺口而默认改用当前股票池、历史指数代理或付费订阅。

## 只比较明确的策略差异

两者都使用[周度动态回测](weekly-dynamic-backtest.md)要求的历史 SPY/QQQ 并集、同一时点数据、两轮漏斗和当周 3–5 只名单。不能用固定 VLO/FTNT/ILMN 或今天的 518 只名单替代这一实验。

| 行为 | A：`rank_rotation` | B：`hold_until_exit` |
| --- | --- | --- |
| 已持有且仍入选 | 按共同风险和目标仓位处理 | 相同 |
| 已持有、本周落选、独立退出未触发 | 目标股数归零，下一可交易时点退出 | 继续纳入持仓管理，不因排名落选而清仓 |
| 独立退出触发 | 优先退出，不因入选排名豁免 | 相同 |
| 新入选股票 | 退出旧仓后，按可用名额和已交收现金买入 | 仅在持仓名额、资金和组合风险允许时买入；不得为了买它而强制清掉落选旧仓 |
| 重新入选 | 继承既有退出记录和冷却期 | 相同 |

“继续持有”指不因横截面排名落选而清仓，不表示仓位或风险状态冻结。共同的持仓上限、风险减仓、保护退出和公司行动规则仍有效。排名落选与技术信号失效必须是不同的原因：不能把 `not_selected` 同时编码成 B 的 `signal_exit`，否则两种策略实际相同。

**独立退出条件**沿用固定趋势研究的规则定义：固定止损 8%、跟踪止损 12%、止盈 20%、持有达到 60 会话、原先独立的量价/趋势持有条件失效，以及账户风险退出。技术条件每个交易会话按当时数据重算；不把“没有进入当周前几名”当作独立技术条件。退出后冷却 5 个完整会话，再等待允许的入场调度。

## 共同实验条件

- 成交区间 2025-07-07 至 2026-10-23，起点各 5,000 USD、空仓。A、B 的资金分别管理；每条路径从头到尾连续，不在周或验证窗口边界重置。
- 使用相同的 68 次周度决策、证券映射、原始价格、因子口径、漏斗权重、阈值、排序和公司行动证据。参数必须在查看 A/B 结果前冻结。
- 目标最多持有 5 只，单股目标上限 25%，总目标上限 75%，整股、无融资。新买入后预计持有的目标集合等权分配总预算，再应用单股上限；其余为现金。
- B 的目标集合先保留未触发独立退出的实际持仓，再按当周候选分数补充剩余名额。落选旧仓不新增资本；不因其分数变低而发出全额退出，但允许共同仓位上限要求的减仓。不得把在途卖单当作已经释放的名额或资金。
- 两者均在组合层检查新买入与实际保留持仓的相关性和风险。沿用漏斗的 126 会话相关性窗口和绝对相关系数 0.85 门槛，限制新增风险；持仓自然变化导致超限须显式记录，不假称所有时刻满足静态门槛。
- 每笔实际成交佣金 1 USD、单边滑点 5 bps；另分别运行 A、B 的双倍成本情景（2 USD、10 bps）。成交数不同，成本总额自然不同。
- 卖出资金到下一会话才可用于新买入，保护规则和跳空处理相同；账户从峰值回撤达到 15% 时清仓停买，状态不自动复位。
- 存在停牌、未成交退出、分红应收、分拆得到的新证券或零碎股权益时，两套账户都保留真实义务。共同事件处置规则在运行前登记，不能给某一版本额外的提前卖出机会。

同一次比较固定为两个主要版本，不是观察收益后反复切换、增加缓冲带或修改持有条件。若要测试“分数差超过阈值才换”“至少持有若干周”等第三种方案，登记为后续试验，保留已查看结果与试验数量。

## 输出与判断

主结果是两条连续账户曲线及成本后收益，同时报告：

| 维度 | 必须输出 |
| --- | --- |
| 收益和风险 | 期末净值、净收益、最大回撤、恢复时间、波动与各时间窗表现 |
| 交易成本 | 成交次数、换手、佣金、滑点、双倍成本结果 |
| 持仓路径 | 实际名额、资金暴露、现金比例、完整持仓周期、加减仓及退出原因 |
| 策略分歧 | 同一周 A 卖出而 B 保留的证券、各自买入/错过的新候选、后续真实净损益贡献 |
| 约束影响 | 因旧仓、名额、资金交收、相关性、冷却或停牌而未能买入的次数及原因 |
| 参照 | 同期 SPY、QQQ 及预先登记的参考组合；都计入一致的费用与分红口径 |

主账户的成本后收益已经扣除交易成本，不能再把费用重复扣入一个人为综合分数。先看数据及对账是否完整，再在既定风险约束内比较净收益、回撤和稳定性；若一方收益更高但回撤也更大，直接呈现权衡，不仅凭终点数字宣布赢家。

可以在决策结束后分析被资金占用挡住的候选后续表现，但这种事后诊断不得反向参与当时的候选或持仓决策。不能把所有“错过的上涨”相加成可实现的额外收益，因为资金与持仓机会互斥。

本区间已被查看，因此本轮只能报告历史滚动对照结果。固定漏斗没有训练步骤时不虚构训练和样本外认证；如追加可学习因子或参数，每窗训练、标签成熟和隔离规则按总规范执行。真正新的留出验证保留在未用于设计的新时期。

## 行为验收

1. 合成场景中，新股票评分更高但旧仓未触发独立退出：A 换出、B 保留；B 保留后仍占用资金和名额。
2. 相同场景让旧仓触发止损或技术信号失效：两者都退出，随后都遵守相同冷却和交收。
3. 若排名不变且无退出差异，两者动作和财务路径一致；不能因账户重置或不同输入制造差异。
4. A 的落选卖单因停牌未成交时，仍保留持仓和风险；B 的保留不能掩盖公司行动或未定权益。
5. 未来名单、价格或修订变化不影响较早结果；周切换和滚动窗口不会重置持仓、净值高点或冷却。
6. 每个主要版本及其成本压力情景都可独立重放；未支持的事件或历史成员缺口必须如实阻止完整结果验收。
