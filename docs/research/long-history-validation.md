# 固定 513 股票的长历史验证

本轮只比较两个已冻结候选：原评分、70 分门槛、单股新仓上限 20%；收益评分、风险合格股票前五名、单股上限 25%。两者都由 QQQ 承接闲置现金，保留原止损、止盈、冷却、持有期及账户风控。基准为纯 QQQ 持有，可用现金继续购买整股。正常与双倍成本分别是每笔 1/2 USD、单边滑点 5/10 bps；现金利息和税款不计入。

免费数据使用 Alpaca SIP 2016-01-04 至 2025-06-30 的日线和公司行动。原始响应逐页保存于新的研究目录，固定名单、证券标识和来源日期从旧研究逐字复制；不得把当前成员日期改写为历史成员日期。原登记的 2017-07-03 起点未通过支付日覆盖预检；在计算收益之前，财务验证区间改为 2020-07-06 至 2025-06-30，采用覆盖足够后第一个完整半年的首个完整交易周，不覆盖 2020 年初暴跌。初始设计及预检失败均保留。候选规则来自后来已观察的 2025—2026 年，故该区间只能称为冻结规则的历史留出检验及滚动伪样本外，不是实际向前推进的未触碰样本外。固定当前成分仍存在幸存者偏差。

每条路径只有一笔初始 5,000 USD，整个区间连续记账。半年统计使用前一会话的期末净值；252 会话滚动统计会重叠，不当作独立重复试验。窗口之间不恢复初始资金、不清空持仓、不过滤失败期，也不重启触发停止风控的账户。没有拟合步骤，因此不把指标计算窗口伪称为模型训练；参数在所有窗口中保持不变。报告累计与分段收益、对 QQQ 超额、最大回撤、成交次数、佣金、滑点和窗口胜率。

最近 253 会话行情不完整、影响价格或股数的历史事件尚未解决或复权无法核对时，记录相应股票当期数据不准入原因，股票仍保留在固定名单中。现金分红支付日不参与价格因子计算，缺失支付日只在实际权益暴露处阻断财务验收，不把它改成选股条件。未上市或无报价期间不填入虚构价格；只有实际报价才能生成成交。持仓缺价时停止并标记不完整，缺价的新买单取消，不按最后价格补成交。未支持事件发生时若有持仓或在途订单，路径的收益不得作为有效验收结果。

Alpaca 的历史 `asof` 是证券映射日期，不是历史数据版本；早期公司行动覆盖、历史更正和独立上市身份仍有边界。免费数据的当前官方说明与限制见 [来源核验](../access/free-long-history-validation-20261027.md)。公司行动只返回空集合不能证明没有事件，提供商记录也不能替代发行方完整核验。所有结果保留 `trade_eligible=false`。

本次实采还发现并单独保存了证券身份与停牌修正：DOW 的当前映射为空，而区间末日映射会返回旧 Dow 前身历史；仅采用经发行方核实的 2019-04-02 起新 Dow Inc. 常规交易。EXE 的当前股份继承 2021 年破产重组后的新 CHK，不采用已注销旧股的早期行情，最早准入 2021-02-10。NBIS 的 2022-02-28 至 2024-10-18 Nasdaq 停牌区间，以及所有零成交量占位记录不构成可执行报价。原始响应和初次规范化快照都保留，新建版本记录排除原因。SKYD 的当前新股尚未覆盖本验证区间，不用 PARA/PARAA 前身补足。SMCI 的长缺口涉及退市后的 OTC 阶段，现有 SIP 输入不能假装覆盖其可执行交易。
