# 每周 SPY 两轮选股漏斗

更新：2026-10-26。目标是从 SPY 官方当前持仓中，连续跟踪并聚焦三至五只值得深入研究的
股票。首版是量价关注漏斗：评分不是上涨概率，也不是已验证的成本后投资收益。
它直接复用现有 Parquet 快照和 Qlib 因子接口，不改写旧研究登记、账户或交易准入。

2026-10-26 明确完整策略回测的目标：每周按当时可得的 SPY/QQQ 历史持仓重建并集，
重跑漏斗，将候选与现有持仓一起决策，延续同一账户并处理退市等事件。
下文的当前观察功能不能代替该历史流程，详见[周度动态回测规范](weekly-dynamic-backtest.md)。

## 数据和两轮规则

官方持仓原字节、Alpaca SIP raw/split 全部分页、实际采集时间均保存在 Parquet/Zstandard。
当前持仓日期与行情日期分别记录，成员文件最多允许落后三个交易会话；不回填成历史成员库。
普通代码保留 `BRK.B`、`BF.B` 等多股类，只有内部标识转为下划线。现金及特殊权益保留在
全量结果中并明确排除。官方行业字段缺失时保持未知，不凭公司名猜测行业。

第一轮最多留下 **50 只**：

- 最近 253 个会话 raw/split 行情完整，价格、成交量、日线边界合法，最新调整口径一致。
- 原始股价至少 10 USD，最近 20 会话平均成交金额至少 2,000 万 USD。
- 价格高于 200 日均线，半年价格收益为正。
- 半年及一年剔除最近一月的价格强度均超过同口径 SPY。
- 按两个相对强度的横截面分位均值排序；相同分数按代码排序，保证可重放。

第二轮以这批候选的横截面分位计算 **0–100 分**：

| 分项 | 权重 | 指标与方向 |
| --- | --- | --- |
| 半年强度 | 25% | 126 会话价格收益，越高越好 |
| 一年强度 | 20% | 252 至 21 会话的价格收益，越高越好 |
| 趋势 | 15% | 相对 200 日均线的距离，越高越好 |
| 波动风险 | 15% | 最近 63 会话日收益标准差乘 sqrt(252)，越低越好 |
| 回撤风险 | 15% | 最近 253 会话价格路径的最大回撤幅度，越低越好 |
| 流动性 | 10% | 20 会话平均原始成交金额，越高越好 |

分位采用 `(平均并列名次 - 1)/(候选数 - 1)`；全部相同或只有一个样本时为 0.5。
相对 SPY 的强度是两个同口径价格收益之差，差值以百分点理解，不是收益比值。
低值更优的指标取反向分位，分项得分加总为总分。权重和阈值在查看本轮结果前固定于
`configs/spy-funnel.toml`，没有通过历史收益搜索选出这些参数。

总分至少 70、年化波动不超过 60%、最大回撤不超过 30%，按总分从高到低选最多五只。
与已入选股票的最近 126 会话收益绝对相关性超过 0.85 时跳过。少于三只合格也保留真实
结果，不降低门槛填满名额。相关性检查不能替代尚未取得的行业分类和行业风险约束。

## 输出和后续研究

`holdings.parquet` 保存所有原始成员及权重；`snapshot/`、`factors.parquet` 保存统一研究
输入及 Qlib 因子；`rankings.parquet` 保存每只股票的初筛结果、总分、分项分数、原因、
数据日期和研究动作；`focus.parquet` 保存重点名单；中文 `report.html` 展示结果。
`changes.parquet` 标记新进入、移出和持续关注，并保存前后分数。规则变化时不计算分数差；
规则相同的分数差仍是当轮候选集合中的相对位置变化，不是公司内在价值变化。

`FOCUS` 是重点研究，`WATCH` 是初筛候选，`EXCLUDED` 是本轮淘汰；全部
`trade_eligible=false`。这些行不能直接传给现有交易动作接口。完整分红和公司行动核验、
基本面估值、财报事件、成本后策略检验和真实账户上下文仍是后续买入建议所需证据。
不输出虚构的买入股数、止损价或盈利概率，也不复用旧空因子池假装这些股票已通过验证。

拆股调整价格不含现金分红，当前持仓回看历史存在幸存者偏差。首版偏向趋势延续，不覆盖
所有低估值反转或突发事件机会；每周运行只能减少遗漏，不能保证发现所有有价值的股票。

## 每周运行

默认北京时间每周日 10:00，在当前聊天运行。取最近完整交易日，节假日按 XNYS 日历回退。
每次使用新目录；读取最近一轮成功报告作为 `--previous`，绝不覆盖旧产物。

也支持以已冻结的 SPY/QQQ 官方响应合并股票池，使用
`funnel-capture --holdings-sources /absolute/path/to/sources.parquet`。来源表保存 `fund`、
`url`、`final_url`、`status`、`captured_at`、`sha256` 和二进制 `body`。只接受指定发行方
接口的成功响应，逐项核验摘要和各自披露日期；重新运行保留原采集时刻。
QQQ 普通股票及 ADR 可纳入，现金、期货、抵销项保留并排除；共同股票只计一行，
`funds`、两个基金的成员日期和权重分别保留，合并权重不求和。

2026-10-26 用户授权以已核对的 518 只股票重跑一轮：成员由 SPY 2026-10-22 与 QQQ
2026-10-23 两份披露合并，行情仍截至 2026-10-23；沿用相同评分配置，SPY 继续作为
相对强度基准，LLM 不参与排名。扩池后的分数属于新的横截面，不能当成公司价值变化。
股票池不同的周际结果不计算可比分数差。本次单轮扩池不自动修改已有每周任务。

```bash
uv run --locked --group research invest funnel-capture \
  --as-of YYYY-MM-DD --output reports/new-week/inputs
uv run --locked --group research invest funnel \
  --inputs reports/new-week/inputs --config configs/spy-funnel.toml \
  --as-of YYYY-MM-DD --previous reports/previous-week/study \
  --output reports/new-week/study
```

首轮省略 `--previous`。凭据默认从进程环境取得；已授权的本地配置可通过
`--credentials-env /absolute/path/to/.env` 只加载两个 Alpaca 字段，不执行配置、不打印密钥。
只访问公开持仓及 `data.alpaca.markets` 历史行情 GET 接口，不涉及账户、订单或订阅。

每周保留报告；名单、分数出现明显变化或发生失败、需要处理时通知，未变化时静默。
这是当前桌面主机的自动任务，需要主机和应用可用，不代表已经部署到 VPS。
[调度说明](https://learn.chatgpt.com/docs/automations?surface=app)

官方文件格式、真实日期、现金和特殊权益、权重差异及免费历史权限见
[主源核查](../access/spy-universe-and-weekly-screening-20261026.md)。

## 首轮验证

2026-10-26 完成首轮：503 只普通股票中，105 只满足基础量价条件，初筛保留 50 只；
5 只达到 70 分，相关性去重后聚焦 3 只。名单及个人研究报告保存在忽略目录
`reports/spy-funnel-20261026-v1/study/`，不写入 Git。

`make check` 572 项全通过，耗时 883.70 秒，总覆盖率 87%；新增 9 项行为回归。
最终构建和独立新目录演示通过；2,500 项指标经过 NumPy 独立重算，容差为预先固定的
2e-5，以容纳 Qlib float32 缓存精度。分项得分加总、评分与风险门槛及相关性约束均通过。
原 13,601 个历史文件与 122 个检查输入摘要一致。
另从封存源码禁用字节码写入后重新运行，成员、因子、排名、重点名单和周际变化五张表的
内容均一致；重放使用新输出目录，派生快照引用相应变化，不作为新的独立策略试验。

原始采集在接口输出字段修正前启动；其日志曾附带不存在的报告路径，后续捕获命令改为
返回 `inputs`。正式名单由最终代码读取、重新验证全部采集后生成。早期导入类型注解错误、
被后续代码修正中断的检查和构建网络限制日志均保留，最终验收采用
`make-check-release.log`、`build-release.log`、`demo-release.log` 和 `verification.log`。
