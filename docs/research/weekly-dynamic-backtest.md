# SPY 与 QQQ 历史周度选股、连续账户回测规范

日期：2026-10-26。状态：周度准入、漏斗与 A/B 连续账户入口已实现并完成合成回放；真实历史成员数据准入尚未通过，复杂公司行动等验收仍有缺口。本文件不是已完成真实回测的报告。

用户确认沿用 2025-07-07 至 2026-10-23 的成交区间、独立 5,000 USD、初始空仓。一次研究只有一个连续账户。原三股结果保留为固定候选池的交易规则研究；36.83% 不能作为本流程的收益，历史文件、账户、注册和样本外状态不改写。

数据预算已由用户限定为免费。付费历史数据仅保留既往核查事实，不作为本轮执行路线；免费覆盖不足时记录缺口，不自动缩短区间或用历史指数成分替代 ETF 持仓。

## 每周流程与三种集合

```text
当时已公开、已生效的 SPY 持仓 ∪ QQQ 持仓 → 当周股票池 U
U 中截至决策时点可用的历史数据 → 第一轮漏斗 → 第二轮漏斗 → 当周候选 S
S ∪ 账户现有持仓 H ∪ 待处理订单和公司行动权益 → 组合决策集合 C
用当时数据及既有账户状态计算 → 新增、持有、加减仓、落选、退出与重入
下一可交易时点成交 → 累计费用、分红、持仓、现金与风险状态 → 下一周
```

- 股票池是两只 ETF 当时实际持仓的并集，不能用今天的 518 只股票贯穿历史，不能无标识地用指数成分替换基金持仓。按证券身份去重，不把同一公司的不同股类合为一只股票。
- 目标每周聚焦 3–5 只。若合格者不足三只，保留不足与现金；不降低阈值补满，也不在看到收益后换规则。
- 漏斗的横截面分位、排名和相关性筛选只基于当周合格股票池。持仓加入组合决策集合，不反过来改变已经生成的漏斗分位。
- 候选名单不能替代真实账户状态。落选、离开 ETF、无报价或停牌的已有持仓，仍保留在账户、估值、风险检查和未完成退出需求中。
- 名单每周更新；保护退出、公司行动、交易状态和未完成订单按交易会话处理。周中不会仅因新的候选出现而重跑一次未登记的全池筛选。
- `FOCUS/WATCH` 仍是研究资格。执行输入、策略假设或因子池、账户上下文分别准入，不能直接把关注行当成券商订单。

## 时间约定与历史准入

沿用当前每周研究的时间约定：北京时间周日 10:00（UTC 02:00）形成周度决策，以此前最后一个完整 XNYS 会话为行情截点，在随后第一个可交易会话开盘代理成交。节假日按日历处理，不用“每 5 个交易日”代替自然周调度。这个约定只定义新回测，不修改现有自动任务。

本区间有 68 次进入成交区间的周度决策，需核验 136 个基金周记录；首个价格截点为 2025-07-03，决策时刻为 2025-07-06 02:00 UTC，首个成交会话为 2025-07-07。最后一轮对应 2026-10-16 截点、10-18 决策和 10-19 起执行。10-23 收盘后的下一周建议另列预览，不算本区间内已经发生的成交。

每项成员事实至少区分：

| 字段 | 用途 |
| --- | --- |
| `security_id`、`symbol`、`fund` | 稳定证券身份、当时交易代码及基金来源；代码改变不能生成虚假的卖出再买入 |
| `membership_as_of`、`effective_at` | 持仓事实对应日及实际生效时点 |
| `published_at`、`available_at` | 原始公开时间及所选信息渠道当时的可用时间 |
| `captured_at`、`source_ref`、`sha256` | 本次取得原件的时间、来源与字节摘要 |
| `revision_id`、`supersedes` | 修订链；保留旧版本，不让今天的更正提前进入历史决策 |

成员加入与移出都要求当时已生效、相应信息在决策截点前可得。已公告但尚未生效的调整不能提前混入实际成员。事后采集时间不能倒填为历史公开时间；仅有日期的来源须先验证时区及保守延迟约定，不能默认当日零点已知。原始基金持仓须以完整版本原子读取，部分响应不能被解释成其他成员全部退出。

不机械要求首次公开时间精确到秒。经核实的历史网页捕获可以作为 `known_by` 可得上界；来源若证明某日已公开且时区明确，可用当地次日零点作保守上界。原始时间仍保留未知，不能把这个上界冒称首次发布时间。上界早于决策截点且其他完整性、时效要求满足时，可作为时点准入证据。免费归档的实证与限制见[归档核查](../access/historical-spy-qqq-free-archives-20261026.md)。

价格、财务、成交量、成员、公司行动、代码映射和修订都执行同样的时点约束。决策不得读取后来发布的数据。周末公开的信息不能倒填为周五收盘已知；交易接口应区分 `price_as_of`、`decision_at` 和 `effective_at`，保留真实时间，不通过改时间戳绕过旧信号契约。

预热至少覆盖首轮所需的 253 个会话，本次共同起点可从 2024-07-01 准备。新上市证券历史不足时记录不满足预热，而不是虚构上市前行情。数据缺失、非上市期、停牌和退市必须分开记录；不得把日线缺失统一补为可成交的前值。

若某周没有合格的历史成员证据，正式历史回测标记 `blocked`，输出该周及基金的缺口；不能换成今天名单、季度披露或删除该周后继续发布完整收益。允许另行登记“仅依赖当时最新公开但滞后的披露”的研究，但那是另一套股票池策略，不冒充本目标。

## 候选与持仓一起计算

周度组合决策读取同一账户的现金、持仓与成本、分红权益、未交收资金、待执行订单、成本高点、持仓年龄、冷却期、净值高点及风险状态。

| 状态 | 必须执行的计算 |
| --- | --- |
| 新入选、未持有 | 检查可交易状态、执行数据资格、冷却、风险及资金预算，合格才买入 |
| 持有且仍入选 | 重算风险和目标股数，产生 HOLD、ADD、TRIM 或风险退出 |
| 持有但本周落选 | 仍计算行情和风险，按事先登记的 `dropout_policy` 处理，禁止从账本中直接删除 |
| 曾退出后重新入选 | 继承退出时间和冷却，不按第一次入场处理 |
| 尚有订单或权益 | 保留到成交、取消确认或权益结清；不可把未知状态视为零 |
| 停牌或无可执行价格 | 保留退出需求，不假设已经卖出或现金已经回来 |

用户随后要求同时回测两种落选策略，不预先决定哪种更好：A 为 `rank_rotation`，按周度目标排名换出落选持仓；B 为 `hold_until_exit`，不因排名落选清仓，直到独立退出条件成立。取消先前暂定的单一默认，将两者登记为同一实验的两个版本，分别延续独立但同起点的账户。共同规则和对照要求见[落选策略比较](weekly-policy-comparison.md)。实际持仓仍须纳入两套策略的组合计算，不因名单消失而删除。

沿用已登记的单股 25%、总目标 75%、佣金 1 USD、单边滑点 5 bps，以及固定/跟踪止损、止盈、最长持有、冷却和账户风险参数作为首版候选设置；新候选池带来的策略变化需要新的研究登记。先生成所有目标差额再模拟执行，按卖出、可用资金与交收限制、买入处理；不假设尚未成交或未交收的卖款可以提前使用。仓位限制是成交预算与后续调仓规则，不能声称盘中价格变化仍维持硬上限。

账户从开始到结束连续运行。周切换、名单变化和验证窗口切换均不得重置资金、持仓成本、风险高点、冷却或暂停状态。独立基准可有自己的初始账户，但各基准内部同样连续，不能每周重置后拼收益。

## 退市与公司行动按事件记账

复权价格仅供按时点构造的因子研究；成交使用原价，现金和证券权益单独记账。不能用今天的全历史复权系数影响当时的价格门槛、股数或成本，也不能在总回报复权价格上再次计入同一分红。

| 事件 | 处理要求 |
| --- | --- |
| 正向拆股、反向拆股 | 使用精确比例同步调整股数、每股成本、保护价格和相关状态；交易订单依事件规则取消或重新生成。必须验证经济价值连续，不能把价格跳变当涨跌或止损 |
| 零碎股、代替零碎股的现金 | 原有整数股交易政策不等于可以丢弃零碎权益。单独保存权益数量；只有核实现金替代金额和到账日后才计现金，不能擅自按收盘价折现 |
| 现金分红 | 正确确定权益，区分除息、登记、支付和实际结算；支付前为应收，不提前作为可用现金。特殊分红和 due-bill 另验事件规则 |
| 股票分红、分拆 | 保存母公司及新证券权益、分配比例、到账和可交易时间、成本分配依据。新证券即使不在当周 ETF 并集，也必须进入持仓管理 |
| 现金收购、换股合并、混合收购 | 按真实对价终止或转换原证券，建立现金应收或新股权益；不得伪装成不存在的市场卖出成交。新证券不自动清除经济持仓历史和未解决风险 |
| 改名、代码或标识变化 | 通过带生效区间的证券映射衔接，保留成本、持仓年龄和风险状态，不生成虚假换手 |
| 停牌、退市、转场外交易 | 保留最后可交易日、交易状态、真实清算/收购/场外处置证据。退市不自动等于归零，也不代表能在最后收盘价成交；不能事后提前卖出以避开事件 |
| 破产或最终清算 | 按已核实的证券注销、赔付与到账记录确认损失或回收；未经证实的残值不得编造 |

事件字段不完整或处理器不支持时保留原事件及持仓，停止将该区间认定为完整可执行回测。若输出暂估净值，必须标明价格陈旧/权益未定，不能作为完整收益验收。问题解决后从同一账本状态重放，不删证券、不裁掉坏区间、不重置资本绕过问题。

Alpaca 官方 [Corporate actions](https://docs.alpaca.markets/us/reference/corporateactions-1) 列出了多类事件，但也明确不保证事件创建和提供时间；字段 `process_date` 与公告时刻不同。`data_quality=complete` 是 API 字段完整性筛选，不证明全历史事件无遗漏。[Mandatory Corporate Actions](https://docs.alpaca.markets/us/docs/mandatory-corporate-actions) 也展示了股票与现金合并、标识变化等独立权益变化。因此不能把当前适配器的整数正向拆股和普通现金分红能力泛化为全部事件已支持。

## 滚动验证

先冻结周度调度、漏斗参数、持仓与退出政策、成本、训练/验证/测试窗口及搜索预算。所有因子挖掘、标准化、筛选或模型拟合仅使用本轮训练区间；有未来收益标签时按实际标签结束时间清除重叠样本，并冻结隔离间隔。

每个测试窗口使用上一阶段已经冻结的规则产生周度名单与动作。下一窗口只能使用届时已经结束、标签已经成熟的数据重新训练；当期测试收益不能用于同窗调参。固定权重漏斗如果没有训练过程，应报告逐窗检验，不虚构模型训练或因子入池。

主验证沿时间前进并延续同一账户，计算拼接后的实际净值、成本、换手、回撤和持仓路径。若额外提供每窗独立从现金开始的诊断，必须另列，不能替代连续账户主结果。

本区间已经被研究者查看，按历史时序重跑只可称 `historical_walk_forward_replay`，不能改成未触碰过的真实留出集。真正新的样本外或前向验证，从规则登记后且未用于本次设计的新期间开始；保留原 `known_through` 和试验记录。

## 首轮程序运行

入口为 `invest weekly-backtest --config <TOML> --output <新目录>`，重放为
`invest verify-weekly-backtest --study <冻结目录>`。输入配置包含 `catalog`、`funnel`、
`start`、`end`、`initial_cash`、`synthetic`、`free_only`、`history_status`、
`max_membership_age` 和 `[policy]`。`snapshot` 与 `[execution]` 成对提供；没有行情时仍可先执行成员准入。
仅接受 `free_only=true`、`history_status="known_history"`，合成输入与真实输入显式隔离。

`weekly_universe.CATALOG_SCHEMA` 定义 typed Parquet 原件目录：逐条保存基金、原 URL、
捕获时间、已公开的时间上界、原件字节与摘要。当前捕获不能反推过去的可得时间；归档原件同时
核对归档时刻和载荷摘要。`membership_coverage.parquet` 保存每个基金周的实际持仓日期、
可得上界、原件引用和阻塞原因。成员缺周时 CLI 返回非零，保存 `blocked` 记录，不产生收益表。

本次真实入口位于 `reports/weekly-replay-20261026-v2/real-study/`：核验 136 个基金周记录，
合格 SPY 记录 1 个、QQQ 记录 0 个，两者同时合格为 **0/68 周**，实际账户回测路径为 0。
这份新记录不改写此前的需求清单或三股研究。

`synthetic-study/` 使用显式合成行情和成员轮换验证 4 周，完成 A/B、各自双倍成本以及
SPY/QQQ 买入持有参照共 6 条路径，81 张表重放一致。Qlib 特征使用仅累计已生效拆股的
向前调整价格；流动性和成交股数使用原价与实际股数成交量，账本单独处理拆股与现金分红。
保留仓位的独立技术信号每日重算，横截面落选不写成技术退出。每条账户路径持续保留资金、
风险状态和冷却期，季度统计直接从该路径切片，不重新注资，也不声称未查看样本外结果。
