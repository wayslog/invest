# R1 固定风险预算研究：预登记方案

本方案针对已发现的资金暴露与永久停用的关系，配置为
[r1-capital-budget.toml](../../configs/r1-capital-budget.toml)。
本文件与配置原文、已知数据截止日、登记时间、源码及依赖锁一起冻结；
讨论日期为 2026-10-20，正式登记时间以 Parquet 为准。

## 依据与唯一假设

既有长窗口研究的六个候选在 2022—2023 训练期全部触发停用。
`rotation-120` 在 2022-12-19 达到高点回撤阈值，之后没有自动清除风险锁，
至训练末期仍为 halted。2024 年六个候选的净值、持仓、成交和订单逐表相同，
不能当成六份相互独立的正面证据。

原等权基准匹配 80% 资金配置，但没有应用策略的单仓退出与账户停用规则；
其收益是机会成本参照，不能把策略和基准的差距全部解释成择时能力。
训练期原候选 19 次成交、佣金 19 美元，不能仅靠降低佣金解释约 695 美元的净损失。

**唯一假设：** 在既有本金保护、单仓退出和 15% 高点回撤停用规则下，
预先将权益预算从 80% 降至 40%、单仓从 40% 降至 20%，能否降低永久停用的发生，
同时仍取得扣费后的正收益并优于匹配资金配置的简单等权基准。
这不是提高既有账户风险限额，也不假设减仓必然提高收益。

## 冻结范围

- 唯一候选：`rotation-120`；`candidate_kinds=["rotation"]`、`lookbacks=[120]`。
  不再延长窗口搜索，不把等价候选重复计数，不在中途更换胜者。
- 标的固定 SPY/XLF，仍为多头、整股、5000 美元独立研究本金；正常成本为每笔
  1 美元佣金、5 bps 滑点；双倍/四倍成本及既有跳空压力保留。
- 21 个会话再平衡、相关窗口 60、阈值 0.95；单仓止损 8%、利润回撤 12%、
  账户高点回撤 15%，本金警戒/终止规则及永久风险锁保持原规则。
- 等权/买入持有使用同一 40% 总预算；100% SPY 与现金分别作为市场和现金参照。
  这些基准不具有策略退出规则，结果必须同时报告回撤和风险状态，不能只比较收益。

## 已知与未来数据

截至 **2026-10-19** 的行情已暴露。2022—2023 为训练，2024 为已知验证，
2025-01-02 至 2026-10-19 为已知复评；所有这些结果均可用于开发，不称为新的独立留出。

未来验证固定为 **2026-10-21 至 2027-04-20**。必须在首日开盘前完成登记；
已知截止日、协议原文和引擎指纹不可在结果出现后改写。中间可以采集行情、核对运行和查看
基础设施健康状况，但不据此调整候选、参数、成本、评价门槛或结束日期。
任何修改进入新的方案，并重新声明截至修改日已知的数据。

## 评价与停止条件

先完整报告已知区间的收益、回撤、首次风险触发、停用时长、持仓暴露、换手、佣金及标的归因。
原风险锁不为改善研究结果而复位。若训练或已知验证已失败，保留失败结论，
不得因此获得正式策略观察资格；未来数据可以继续检验原假设，不将失败记录删除。

未来窗口结束后一次性运行冻结研究并完整重算。M2 的既有资格门槛保持不变：
训练/验证/留出均 active，验证和留出净收益为正且超过匹配等权，留出回撤不超过 15%，
双倍成本验证仍为正，数据来源和登记时点检查通过。另报告真实会话数、交易数、
现金占比及独立对账；少量交易或六个月的结果不等于长期有效性证明。

未来窗口未结束时不运行不完整的 holdout，也不改用已知历史填充。
现有现金运行账户的 ID、5000 美元、冻结观察窗口和风险历史均不因本研究而改变；
本研究登记不自动创建正式或影子资金账户。

## 登记

```bash
uv run --locked invest research-propose \
  --config configs/r1-capital-budget.toml \
  --protocol docs/research/r1-capital-budget.md \
  --known-through 2026-10-19 \
  --output reports/research/r1-capital-budget-registration
```

该目录不可覆盖；实际登记须使用本轮最终验收的引擎。
