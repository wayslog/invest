首个适配器选择 **Alpaca Market Data**：官方资料提供原始日线和企业行动接口，可与自有 paper
账本分离使用。首次接入只需要读取数据；向 Alpaca paper 提交订单属于后续 M4 的工作。
已验证的权限限于此次历史查询，其他时段、实时行情和完整企业行动覆盖不作推断。

## 已核实事实与尚未核实事项

Alpaca [Historical bars 官方说明](https://docs.alpaca.markets/reference/stockbars)
区分原始价格与拆股/分红调整，并区分 **SIP 综合 feed** 和 **IEX 单一交易所 feed**。
这会影响 OHLC、成交量和模拟开盘成交的解释，适配器应明确指定并保存 feed，不能静默
从 SIP 降级到 IEX 后仍使用同一数据版本。SIP 是否可读、历史起点、最近数据延迟、
请求限额和最终费用，要以账户实际试读及当时的订阅条款为准。

此前在 2026-10-19 对 `data.alpaca.markets/v2/stocks/SPY/bars` 做了不带凭据的只读探测
（2024-01-02 的原始 IEX 日线），返回 **HTTP 401**。这确认该次请求需要认证，
不能据此推断特定账户拥有或缺少某种 feed 权限。用户随后配置凭据后，已成功读取
`/v2/stocks/bars` 的 SPY 2024 年 SIP 日线及 `/v1/corporate-actions`，详见
[真实访问证据](milestones/m1.md#真实访问与回放证据)。

官方 [企业行动客户端](https://github.com/alpacahq/alpaca-py/blob/master/alpaca/data/historical/corporate_actions.py)
使用 `/v1/corporate-actions`；[数据模型](https://github.com/alpacahq/alpaca-py/blob/master/alpaca/data/models/corporate_actions.py)
中现金分红的 `payable_date` 可空，且包含反向拆股、合并等当前引擎不支持的事件类型。
这些是接口能力证据，本身不证明历史事件完整或当时可得。SPY 2024 年的四笔现金分红
已另与 State Street 官方历史表逐笔核对，金额、除息日和支付日完全一致，
见 [独立核对记录](milestones/m1.md#发行方独立分红核对)；结论不扩展到其他事件或区间。
当前适配器已显式拒绝缺失的必要字段和不支持事件，不以 0 或 1 冒充“无事件”。
映射和失败处理由人工 API 响应测试覆盖；SPY 指定真实区间已另行运行并核对，
不能把单个成功区间推广为全市场兼容性证据。

真实响应暴露了日期口径差异：按处理/支付日在 2024 年筛选，会遗漏 2024 年 12 月除息、
2025 年支付的分红。`alpaca.v2` 捕获截至冻结日期的全部可用处理记录，再按除息日选择
研究区间；原始响应保留在 Parquet 中，区间外事件不被错误计入新账户。

Alpaca 的 [数据服务说明](https://docs.alpaca.markets/docs/about-market-data-api)
用于比较方案；[Schwab 官方产品页](https://developer.schwab.com/products/trader-api--individual)
仅证明产品入口存在。文档访问成功不能替代账户权限核查。

## 日历选择

使用锁定依赖中的 `exchange-calendars`，首轮采用 XNYS 常规时段。参考
[库文档](https://github.com/gerrymanoim/exchange_calendars) 和
[NYSE 交易时间及休市安排](https://www.nyse.com/markets/hours-calendars)。
已增加节假日、半日市、夏令时及 2025-01-09 特别休市的自动检查样例。
实际分钟对照已确认：日线不能被解释成常规时段分钟线的简单汇总；日历也不能证明
数据何时发布。六个日期为 2024-01-31、03-08、03-11、07-03、07-05、11-29，覆盖
正常交易日、夏令时切换两侧和两次半日市，均使用 raw SIP。

| 对照例 | 日线 open | 常规时段首分钟 open | 日线成交量 | 常规时段分钟成交量合计 |
| --- | --- | --- | --- | --- |
| 2024-01-31 | 488.62 | 488.62 | 126011062 | 102937185 |
| 2024-07-03 半日市 | 548.69 | 548.68 | 32789911 | 25828148 |
| 2024-11-29 半日市 | 599.66 | 599.64 | 30177351 | 20793986 |

六日的成交量均有差异，两次半日市开盘价也不同。常规分钟窗口为 `[XNYS open, close)`；
它未覆盖交易级别的资格标记、收盘竞价和修订，因此不能用分钟聚合倒造“正确”日线。
保留供应方 OHLC/volume，开盘只作历史撮合代理，成交量不参与开盘时的成交选择。
采集门槛采用次日纽约 00:15，早收到的行情页不能靠晚收到的企业行动页获得准入。
该门槛是保守工程规则，不是供应方 SLA，也不证明历史发布时点或之后不再修订。

原始分钟响应、限额头和类型化对照分别保存于 `reports/milestones/m1-final/` 下的
`minute-probes.parquet`、`rate-limits.parquet` 和 `daily-minute-comparison.parquet`。
当前命令和报告契约见 [Parquet 数据约定](data.md#交易日历与质量报告)。

   记录，依据是用户账户信息，不是 API 返回账单。未购买或修改任何订阅。
   历史 SIP 成功不证明实时 SIP 可读，也不包含未来升级套餐的授权。
4. 六次历史请求的 `X-RateLimit-Limit` 均为 `200`；已留档剩余额度与 reset 头。

5. 观察时间、修订批次和未知发布时间分别记录；现金分红核对不证明其他行动完整，
   空参考集不被当作无事件。准入范围为明确假设下的历史研究，不是实时订单执行。
