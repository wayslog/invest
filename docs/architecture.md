# 项目边界与后续方向

当前版本是 Python 3.12 的研究基础：本地 CSV → 输入校验 → 单资产统计 → JSON 输出。
`analysis.py` 负责计算，`cli.py` 负责命令行输入输出，测试与网络、账户无关。

按实际需求逐步加入以下模块，不提前绑定行情商或券商：

1. 数据层：行情适配器、本地缓存、交易日历、拆股与分红处理。
2. 研究层：因子、股票池、信号与参数实验。
3. 回测层：持仓、现金、成交时点、手续费、滑点与基准比较。
4. 组合层：仓位约束、风险指标和再平衡。

研究数据应明确交易日、时区（美股通常为 `America/New_York`）和币种；
日线交易日是日期，不能当作 UTC 时间戳随意转换。金额记账应采用 Decimal 或整数最小
货币单位，当前浮点价格仅用于统计计算。后续回测必须明确数据可获知时间，避免前视
偏差、幸存者偏差，以及复权价格和实际成交价格混用。

当前收益是输入价格序列的首尾比值，回撤只衡量给定观测点；不包含资金进出、交易成本、
税费、汇率或现金收益。若需要包含分红的总收益，必须由数据源提供对应复权口径，
本项目不会从普通收盘价推断分红再投资收益。
